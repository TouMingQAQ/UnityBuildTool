TBuildTool · 使用指南与构建原理

💡 构建工作流说明

1. 在 Profile 与排期 页面设置项目根路径并点击「扫描 Profile」。

2. 点击「＋ 添加」将需打包的目标加入队列（支持 Windows、Android、iOS）。

3. 点击队列项中的「⚙ 高级配置」，可单独配置构建缓存目录、成品命名规则、Addressables 构建、DEV 调试包及安卓 Keystore 签名。

4. 在 构建主页 随时点击「开始批量打包」，实时监控阶段与日志输出。

📦 产物归档与平台特性

• 共享��建缓存：多个 Profile 可指定相同构建目录（如 Builds/SharedCache），共享 IL2CPP、Burst 与 Shader 编译缓存，大幅加速批量构建。

• 自定义命名替换规则：支持 {Platform}、{Product}、{Profile}、{Version}、{VersionCode}、{Time}、{Date}、{Dev} 等宏占位符。

• iOS Xcode 自动压缩：iOS 目标导出 Xcode 工程后，自动打包为包含完整工程的 .zip 归档。

• Windows 自动压缩：Windows 构建包构建完成后自动打包为标准 .zip 归档包。
